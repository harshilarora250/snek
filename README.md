# Apple Snake!
Find a apple, with your snake -|-

## How it Works
The game is coded in  ```python``` and uses the ```pygame``` library! You can look at the ```main.py``` document to understand the code, although it is very simple!

## How you can make changes
To make changs for yourself, first you must clone this repository locally, by running the command below in your terminal.
```
git clone https://github.com/harshilarora250/snek.git/
```
Once cloned, you can open the folder in your preffered IDE (I recommend VS Code) to start making changes, either yourself, or with a coding agent! You can start making changes in your terminal as well, by running the commands below!
```
cd snek
nano main.py
```
